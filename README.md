# Vórtex Voice

**Tu voz a texto, sin límites.** App de Vortex Company, parte de la suite Vórtex Studio.

Dictado por voz con transcripción en tiempo real usando la SpeechRecognition API del navegador (Chrome, Edge, Brave y Samsung Internet, en PC y Android).

- Botón Grabar / Pausar / Continuar / Detener con cronómetro y contador de palabras.
- Selección de idioma (español Latinoamérica, Nicaragua, España, México e inglés US).
- Texto provisional en gris mientras dictas y pulido automático de mayúsculas y signos.
- Guardar la transcripción en un documento `.txt`, copiar al portapapeles o **enviar directamente a Vórtex Notes** (se abre como nota nueva con etiqueta `voz`).

## Características

- Gratis, sin anuncios y sin cuentas de usuario.
- Todo el procesamiento ocurre en tu navegador: ninguna foto, grabación o texto se sube a ningún servidor.
- Funciona en PC y móvil (los permisos de cámara/micrófono se piden solo cuando los usas).
- Soporte oficial: [vortexmusic.soporte.app@gmail.com](mailto:vortexmusic.soporte.app@gmail.com)

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · lucide-react · Web Speech API
